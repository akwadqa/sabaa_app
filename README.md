# sabaa

🚚 Field Sales & Delivery Management App that helps teams manage orders, customers, and deliveries in the field. Users can create orders, connect with supermarkets, track inventory, and handle deliveries efficiently. Supports multiple roles including 🚐 Vansell, 🧑‍💼 Salesman, and 🚛 Driver for streamlined operations.
